# Sicherheit

Die Skills sind Textanweisungen ohne ausführbaren Code; die Skripte in `scripts/` laufen nur lokal oder in der Prüfung des Repos. Eine Sicherheitslücke im engeren Sinn ist hier selten. Melden Sie trotzdem, wenn Ihnen etwas davon auffällt:

- Ein Skill bringt ein Modell dazu, Daten preiszugeben, Prüfungen zu überspringen oder Zahlungen ohne Rückfrage zu empfehlen.
- Ein Beispiel enthält echte personenbezogene Daten oder echte Zugangsdaten.
- Ein Skript oder Workflow lässt sich missbrauchen.

## Melden

Bitte nicht als öffentliches Issue, sondern per Mail an **info@kiintegration.com**, Betreff „Sicherheit Skills-Repo". Beschreiben Sie, welcher Skill oder welche Datei betroffen ist und wie sich das Problem zeigt.

Wir bestätigen den Eingang innerhalb von 3 Werktagen und melden uns mit einer Einschätzung, sobald wir das Problem nachvollzogen haben. Wer meldet, wird auf Wunsch im CHANGELOG genannt.

## Unterstützte Fassung

Gepflegt wird nur der aktuelle Stand auf `main`.
